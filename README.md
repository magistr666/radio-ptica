# Радио птица

Онлайн-радио «Радио птица» — одностраничный сайт с плеером прямого эфира, программой передач и контактами.

## Как запустить локально

Просто откройте `index.html` в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `radio-ptica`).
2. Загрузите файлы этого проекта в репозиторий.
3. В настройках репозитория (Settings → Pages) выберите ветку `main` и папку `/ (root)`.
4. Сайт будет доступен по адресу: `https://<ваш-логин>.github.io/radio-ptica/`

## Настройка потока

Откройте `js/player.js` и укажите адрес потокового вещания в переменной `STREAM_URL`:

```js
const STREAM_URL = 'https://radio.example.com/stream.mp3';
```

## Структура

```
radio-ptica/
├── index.html       — главная страница
├── style.css        — стили
└── js/
    └── player.js    — логика плеера
```
